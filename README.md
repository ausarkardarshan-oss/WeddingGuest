# Wedding Guest List Management System

## About
A web application to manage wedding guest details using HTML, CSS, Java, JSP, and MySQL.

## Features
- Add guest details.
- Select Bride or Groom side.
- Validate user input.
- View and filter guest records.
- Calculate total members.

## Technologies
- HTML and CSS
- JavaScript
- Java and JSP
- MySQL
- Apache Tomcat

## Database
Database: `wedding_db`  
Table: `wedding_guest`

## How to Run
1. Start MySQL and Apache Tomcat.
2. Create the database and table.
3. Deploy the project in Tomcat's `webapps` folder.
4. Open `http://localhost:8080/WeddingGuest/index.html`
